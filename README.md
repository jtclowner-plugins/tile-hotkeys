# Tile Hotkeys

Tile Hotkeys is a RuneLite plugin for switching between imported ground marker packs with hotkeys. Organise packs into named groups and give each group its own hotkey and mode.

## Getting started

1. Open the Tile Hotkeys sidebar and choose **New group**.
2. Expand the group, then choose **+ Add pack** to import copied Ground Markers.
3. Set the group's hotkey and mode. Drag tile packs by their handles to change the cycle order.

## Group modes

- **Toggle group** (default) switches all packs in the group on or off with each press.
- **Cycle through** advances one step per press. **Add spacer** adds a step with no tiles.
- **Show while held** shows the group while you hold the hotkey.
- **Hide while held** hides the group while you hold the hotkey.

## Import and export

- **Import pack** and **Export pack** uses Ground Markers JSON from the clipboard.
- **Import group** and **Export group** uses a Tile Hotkeys object for all packs in the selected group plus the hotkey and the mode.
